## Platform

web

## Product Purpose

This is a responsive web portfolio for Erik Hein. Repository metadata describes him as a product engineer in San Francisco building AI products and creative, interactive interfaces; the page copy describes end-to-end software engineering work.

## Capabilities and Constraints

The single-page site presents an interactive keyboard hero, biography, selected projects with external links, categorized skills, experience, a résumé link, social links, and a contact form. Navigation connects the Home, About, Work, Skills, Experience, and Contact sections. WebGL scenes, motion, smooth scrolling, a command palette, and sound controls are existing parts of the experience.

Implementation constraints: Next.js 14 App Router, React 18, TypeScript, Tailwind CSS, Framer Motion, Three.js / React Three Fiber, and Lenis. The package requires Node.js 20 or later.
